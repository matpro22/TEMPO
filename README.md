# ⏱ Tempo — gestion de temps et de projets (BTS CIEL)

Application web de gestion du temps et des projets pour le BTS CIEL, dans un style Apple « liquid glass » :

- **Emploi du temps** interactif avec alternance des semaines A/B, vacances et devoirs liés aux cours
- **Projets** avec tâches, journal de bord (format BTS, compétences, export PDF), notes enrichies, jalons, liens et suivi du temps
- **Diagramme de Gantt** interactif : glisser-déposer, dépendances, zoom, export en image et PDF
- **Kanban** (souris et tactile), tâches répétées, modèles de projets
- **Devoirs et contrôles** avec moyennes, **calendrier**, **Pomodoro**, **statistiques**, récap de la semaine
- **Rappels** et export vers le calendrier (.ics)
- Installable sur iPhone (PWA), fonctionne hors ligne, synchronisation privée entre appareils via un Gist GitHub

## Utilisation

- **En ligne** : ouvre le site GitHub Pages. Sur iPhone : Safari → Partager → « Sur l'écran d'accueil ».
- **En local** : ouvre `index.html` dans Chrome ou Edge.
- **Synchronisation** : Réglages → « iPhone & synchronisation », puis colle un jeton GitHub qui n'a que l'autorisation `gist`.

Les données personnelles ne sont pas dans ce dépôt : elles restent sur l'appareil, et dans un Gist privé si la synchro est activée.
